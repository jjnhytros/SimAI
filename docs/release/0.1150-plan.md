# Piano release 0.1150 — Training esperienziale

**Data**: 2026-10-29
**Tipo**: feature (tocca `process_payday` → 10y obbligatorio)
**Base**: 0.1140 (387 test verdi, `10y-0.1140.json`, tps 73.9)

## Motivazione

0.1140 ha introdotto `Skill` e lo scaling salariale, ma le skill
sono **statiche**: i livelli del seed non cambiano. 0.1150 introduce
il training esperienziale: chi viene pagato guadagna +0.005 punti
nella propria skill. Le skill diventano dinamiche, i salari crescono
nel tempo.

## Scope

1. `train(session, char_id, kind, amount)` in `skills/service.py`.
2. `TRAIN_PER_DAY = 0.005` in `skills/service.py`.
3. `process_payday`: dopo il pagamento, `train(char.id, _skill_for(job), TRAIN_PER_DAY)`.
4. CLI `npc skill-train -c <key> -s <skill> -n <amount>`.
5. Test: `train`, cap, creazione, payday integra, secondo payday più alto.

## Non-scope

- Training action nel catalogo (`PRACTICE_*`, `STUDY`, `COOK`):
  0.1160. Richiede `ActionDef.satisfies: NeedKind | None` e
  adattamento di `filter_by_need_threshold`, `apply_effect`, `score`.
- Skill decay: 0.1160. Decisione: no decay in 0.1150.
- Job promotion: 0.1160+.
- Multi-skill job: 0.1160+.

## Design

### `train`

```python
def train(session, character_id, kind, amount) -> Skill:
    skill = skill_of(session, character_id, kind)
    if skill is None:
        skill = Skill(character_id=character_id, kind=kind, level=0.0)
        session.add(skill)
        session.flush()
    skill.level = clamp_level(skill.level + amount)
    return skill
